# 🌈 Rainbow Run 🌈

## How far can you make it?

🦄 Avoid obstacles and collect crystals!

🦄 Upgrade your run with crystals!

🦄 Post your highest score to the shared leaderboard!

## Controls
**Desktop**: Arrow Keys

**Mobile**: Swipe

Left/Right - Change Lanes

Up - Jump (or Space)

Down - Slide
